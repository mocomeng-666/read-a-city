# 全景生图提示词模板（API 版，已在两地验证）

**分工**：准确交给漫步图（按地图数据画），全景只负责让人感到这片街区的气质。所以全景最多给模型 **3 个必须画对的锚点**，其余自由发挥。编号牌只标锚点对应的点，其余点在图例里注明“见漫步图”。

**为什么这样定**（永平四版试验，2026-11-03）：要求画准的东西有八九个时，限制少就位置乱，限制死就照着草图描，逐条点名又会改一处丢一处。问题不在字数，在“必须画在某个位置的东西”有几个。

## 准备

1. 参考图只给一张**轻量布局草图**：代码版全景去掉文字、编号牌、图例，**也去掉填充用的普通楼房**，只留道路、水面、锚点所在的那片房子和少量树。草图越密，模型越会照着描。`panorama.py` 会写出 `<全景>.sketch.svg`，截成 1080×1920 的图即可。
2. 选 3 个锚点：大、好认、和故事有关（一条河和桥、一片老房子、一座矿山或塔）。小地标（亭子、石塔、门楼）不当锚点，交给读本和漫步图。
3. 只填花括号，其余照抄。

## 模板

```text
画一张手绘钢笔淡彩插画：从高空斜着俯瞰{一句话：什么样的地方}，有透视，近大远小，画面铺满，像旅行手账里的街区全景。

参考图只是一张布局草图，不是要临摹的画：只借用它的视角和{主要河流、道路}的大致走向。草图里的梯形边界、方块房子、点状小树都不要出现，全部重新画成真实的插画。

这片街区的样子：{两三句：房子是什么样、高矮新旧怎么混、有什么日常生活的细节；也写清楚它不是什么，比如“不是古镇景区”}

画面里一定要有这三处，位置大致如下：
1. {锚点 1：是什么，在画面哪个方位，大概多大}
2. {锚点 2}
3. {锚点 3}
其他地方自由发挥，但不要加草图里没有的河道或大路。

留白：顶部约六分之一只画淡淡的天空，底部约七分之一只画平淡的地面或水面。

风格：钢笔淡彩，线条略带手绘抖动，轻微水彩晕染；暖色纸张底 #f6efe2，墨线 #3b3227，水面 #a9c6cf，树用柔和的灰绿；工作日上午，光线柔和，只有零星远景小人，不画脸。

不能出现：任何文字、数字、字母、招牌、匾额、对联、门牌、水印、圆点标记；古装人物和历史场景。
```

## 生成后

- 检查：无字（放大看招牌）；三个锚点都在、方位大致对；像插画不像描图；不像景区。
- 只给锚点对位编号牌，其余点不标。位置文件里写 `legend` 和 `overlay_notes` 可以覆盖配置里的图例和说明。
- 不合格时先只重画一次，不逐条加限制；两次都不行就换模型或改画分镜。

## 验证记录（万相 wan2.6-image，2026-11-03）

| 地方 | 草图 | 结果 |
| --- | --- | --- |
| 永平 | 原草图（本身稀疏：田地和点状树） | 一次成功。三个锚点都在，像插画，无字。比之前逐条调的四版都好。矿山偏大、偏裸 |
| 沙井 | 原草图（满是方块出租楼） | 不合格。正中老村、水塘、河涌画对了，但画面其余部分照描方块 |
| 沙井 | 轻量草图（去掉出租楼） | 合格。三个锚点都在，无字，像插画。但出租楼画成了间距宽的八九层板楼，没有握手楼的密；比 Codex 那张一次成功的图差一截 |

结论：3 个锚点 + 固定模板 + 轻量草图，换地方能一次出可用的图；但画面的丰富和准确程度受模型本身限制，万相不如 Codex 那次。

## 换模型对比（Seedream 5.0 flash，2026-11-03）

同一份永平模板提示词、同一张参考图（`01-panorama-sketch-full.png`），一次成功，约 27 秒。

| 检查项 | 万相 t1 | Seedream sd1 |
| --- | --- | --- |
| 三个锚点 | 都在 | 都在，老房子是一组带院子的灰瓦大屋，比 t1 更显眼 |
| 像插画、细节 | 好 | 更好：街边店面、电线、行人、河堤都更丰富，更像“有人过日子的镇子” |
| 矿山 | 偏大偏裸 | 台阶和草更像复绿的老矿，但台阶仍有点像梯田 |
| 石桥位置 | 下方三分之一 | 偏低，压到底部留白区，一部分被图例面板遮住 |
| 无字 | 无字 | 店招上有看不清的类文字笔画（很小，不可读） |

结论：同样设置下 Seedream 的画面明显更丰富，模板换模型直接可用；缺点是不太守留白，店招会冒出类文字。
