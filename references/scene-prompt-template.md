# 历史场景示意画：提示词模板

一份读本配 3–4 张，每张画一个资料里写到的具体场面（码头卸货、桥头早市、戏台、年货市场、工厂下班）。画面围绕人和生活，不画地图。

## 先写依据（放在提示词文件开头，不发给模型）

```markdown
# 图卡 0X · 历史场景示意：<年代>的<地点>

画面只用《<来源>》里写到的东西：
- <人：什么人、在干什么>
- <物：卖什么、用什么>
- <场景：时间、天气、热闹程度>

不得补造：<资料没写、但模型可能自作主张的东西，比如招牌字号、具体人物长相>
```

资料里找不到具体场面的站，不画。那一站用老地图、老照片，或者一句画面感强的引文补，也可以和相邻站合并。

## 提示词（照填）

```text
画一张手绘钢笔淡彩插画，竖版，像旅行手账里的一页：<年代>中国<城市>，<地点>，<一句话场面>。

视角：<站在哪里、往哪里看；人站的高度>。

画面里的人和事：
1. <资料里的第一件事，写成能画出来的动作>
2. <第二件>
3. <第三件>
4. <第四件，最多五六件>
5. 来往的人里有<资料里出现的身份，比如劳工、商人、学生>。

人物都画得小而概括，不画清楚的面部特征。<时间和光线，比如：早晨，光线柔和，空气里有点烟和水汽>。

风格：钢笔淡彩，线条略带手绘抖动，轻微水彩晕染；暖色纸张底 #f6efe2，墨线 #3b3227；整体像老照片褪色后的暖色调。顶部约六分之一留给淡淡的天空或屋檐，底部约七分之一画平淡的地面（要叠标题和页脚）。

不能出现：任何文字、数字、字母、招牌字、匾额、对联、水印；现代建筑、汽车、电线、塑料制品、双肩包；古装戏服人物。
```

## 生成和做卡

```bash
python3 -I scripts/gen_image.py --prompt <prompt.md> --out images/0X-<名字>-scene.png          # 演练，看费用
python3 -I scripts/gen_image.py --prompt <prompt.md> --out images/0X-<名字>-scene.png --send   # 用户同意后
python3 -I scripts/scene_card.py source/card-0X.json images/0X-<名字>-card.png
```

`card-0X.json` 的标签用 `"label_space": "image"` 时，直接写原图像素坐标（看原图量出来），脚本会换算。标签 3–4 个，指向资料里写到的东西；有假字的地方也用标签盖住。

## 看图检查

- 资料里写到的东西画没画；
- 放大看有没有可读的字（招牌、匾额）；
- 有没有现代物件（双肩包、塑料桶、电线杆）；
- 模型自己决定的东西（建筑样子、某样食物画成了什么），写进卡片页脚的说明。

不合格时只重画一次；还不行就保留能用的部分，在页脚说明。
